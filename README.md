# Elkartea\_TPV

# 

# Proiektuaren deskribapena

# 

# Elkartea\_TPV elkarte gastronomiko baten kudeaketa errazteko garatutako mahaigaineko aplikazioa da. Aplikazioaren bidez erabiltzaileak, biltegia, kontsumoak eta mahai-erreserbak kudeatu daitezke.

# 

# Proiektua C# programazio-lengoaiarekin eta WPF teknologiarekin garatu da, eta datuak SQLite datu-base batean gordetzen dira.

# 

# Erabilitako teknologiak

# 

# \- C#: aplikazioaren programazio-lengoaia.

# \- WPF: erabiltzaile-interfazea garatzeko.

# \- SQLite: datuak gordetzeko datu-basea.

# \- Visual Studio: garapen-ingurunea.

# 

# Aplikazioaren funtzionalitateak

# 

# \- Saioa hastea: erabiltzailearen izena eta pasahitza erabiliz aplikazioan sartzea.

# \- Erabiltzaileen kudeaketa: erabiltzaileak sortu, ikusi, editatu eta ezabatzea.

# \- Biltegiaren kudeaketa: produktuak gehitu, aldatu eta ezabatzea, eta stockaren kantitatea eta prezioa kontrolatzea.

# \- Kontsumoen kudeaketa: produktuak aukeratu, kantitatea zehaztu eta kontsumoa erregistratzea.

# \- Stock-aren eguneraketa: kontsumo bat amaitzean, biltegiko kantitatea automatikoki eguneratzea.

# \- Erreserben kudeaketa: mahaiak eta erreserben datak kudeatzea, bazkaria eta afaria bereiziz.

# 

# Aurrebaldintzak

# 

# Aplikazioa martxan jartzeko, honako hauek behar dira:

# 

# \- Windows sistema eragilea.

# \- Visual Studio instalatuta.

# \- .NET SDK, proiektuak eskatzen duen bertsioa.

# \- Git, proiektua GitHubetik deskargatzeko.

# 

# Proiektua deskargatzea

# 

# 1\. Ireki proiektuaren GitHub biltegia.

# 2\. Sakatu Code botoian.

# 3\. Kopiatu HTTPS helbidea.

# 4\. Ireki terminala eta exekutatu:

# 

# git clone GITHUB\_BILTEGIAREN\_HELBIDEA

# 

# 5\. Ireki deskargatutako proiektua Visual Studio erabiliz.

# 

# Aplikazioa martxan jartzea

# 

# 1\. Ireki `Elkartea\_TPV.sln` fitxategia Visual Studio erabiliz.

# 2\. Itxaron beharrezko paketeak kargatu arte.

# 3\. Ezarri `Elkartea\_TPV` abiarazteko proiektu nagusi gisa.

# 4\. Sakatu Start botoia edo `F5` tekla.

# 5\. Aplikazioan saioa hasteko leihoa agertuko da.

#
